# Week 2 — Data Collection, Cleaning & Preprocessing

## Project
Two-Wheeler Last-Mile Logistics Analytics

## Objective
This week focuses on collecting, cleaning, and preprocessing logistics data for further analysis.

## Data Preprocessing
The preprocessing workflow includes:
- Loading the raw logistics dataset
- Checking the structure and data types
- Handling missing values
- Removing duplicate records
- Standardizing categorical values
- Detecting and handling outliers
- Preparing the cleaned dataset for analysis

## Files

- `data-raw/` — Original/raw dataset
- `data-clean/` — Cleaned dataset
- `data_preprocessing.py` — Python preprocessing code
- `Data_Preprocessing_Report.docx` — Detailed Week 2 report

## Tools Used

- Python
- Pandas
- NumPy
- Scikit-learn

## Outcome

The cleaned dataset is prepared for the next stage of logistics data analysis and visualization.
